# Quickstart

Setup guides. Work through these before the session that needs them — each one says when it is due.

| Guide | Needed by | Status |

HW2 is an individual assignment. Course staff provision the same isolated
two-node topology for each student; students do not create their own
realizations.

Each quickstart is written to be followed without help. If you get stuck on a step, that is a bug
in the guide — report it and it gets fixed for everyone.
