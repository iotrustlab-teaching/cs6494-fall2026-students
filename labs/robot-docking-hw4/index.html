Safe approach: whenever a sampled position is inside that region during seconds 0–5, speed must be at most 0.2 m/s.

Part 2 is a separate check: edit STUDENT_FORMULA in student_spec.py, then run .venv/bin/python hw4.py check-spec --out runs/my_formula_check.json. That command uses RTAMT on supplied and authored eight-sample examples. It does not change the fixed checker on this page.

What does RTAMT actually do here?

The Python model produces motion states every 0.05 s. We extract eight whole-second samples. RTAMT evaluates the fixed STL formulas on those samples and returns service and speed robustness scores. A direct check of the same samples decides PASS/FAIL at exact inclusive boundaries, where a zero score alone can be ambiguous. The Part 3 PSY-TaLiRo search minimizes RTAMT's fixed speed score; it does not search your editable student formula.

The speed formula uses dimensionless distance and speed terms scaled by 0.5 m and 0.2 m/s; its score is not added to a margin in metres. If the robot never enters, the conditional speed rule is logically true but marked NOT EXERCISED; that does not demonstrate docking.
