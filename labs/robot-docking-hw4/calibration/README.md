# Staff-supplied calibration runs

These JSON files are fresh model executions with the original 0.8 m brake point. They are supplied for retesting, not student search discoveries. The adverse case uses 1.2 m/s cruise and 1.0 m/s² braking; the normal mission uses 1.5 m/s and 1.5 m/s²; the additional case uses 1.2 m/s and 1.6 m/s². Use hw4.py replay to verify a case before comparing a policy change.
